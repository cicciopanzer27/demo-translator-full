# 📄 Traduttore Documenti Legali Offline

Sistema professionale per la traduzione automatica di documenti PDF legali con preservazione del layout originale.

## 🚀 Avvio Rapido

```bash
# Avvia l'applicazione
venv\Scripts\python.exe src\main.py
```

## 📁 Struttura Progetto

```
TRANSLATOR_LAC/
├── src/                    # Codice sorgente principale
│   ├── core/              # Componenti core del sistema
│   ├── extractors/        # Estrattori PDF (nativi e OCR)
│   ├── generators/        # Generatori documenti output
│   ├── ui/                # Interfaccia utente PyQt6
│   └── main.py            # Punto di ingresso
├── documents demo/         # Documenti di test
├── output/                # Documenti tradotti
├── models/                # Modelli traduzione
├── _DOCS/                 # Documentazione
├── _SCRIPTS/              # Script di utilità
├── _TESTS/                # Test e validazione
└── _OLD_FILES/            # File obsoleti
```

## 🎯 Funzionalità

- ✅ **Traduzione offline** completa
- ✅ **Documenti PDF nativi** e scannerizzati
- ✅ **Preservazione layout** originale
- ✅ **Interfaccia moderna** PyQt6
- ✅ **OCR automatico** per documenti scannerizzati
- ✅ **Generazione DOCX** professionale

## 📋 Requisiti

- Python 3.8+
- Windows 10/11
- 4GB RAM minimo
- 2GB spazio disco per modelli

## 🔧 Installazione

```bash
# Installa dipendenze
pip install -r requirements.txt

# Avvia applicazione
python src\main.py
```
