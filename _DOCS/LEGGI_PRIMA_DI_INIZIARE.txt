═══════════════════════════════════════════════════════════════
🚀 AVVIO RAPIDO (3 SEMPLICI PASSI)
═══════════════════════════════════════════════════════════════

PASSO 1: Crea icona sul desktop
   → Doppio click su: CREA_ICONA_DESKTOP.bat
   → Conferma quando richiesto

PASSO 2: Avvia il traduttore
   → Clicca sull'icona "Traduttore Documenti" sul desktop
   → Oppure esegui: python src\main.py

PASSO 3: Traduci il primo documento
   → Nella finestra che si apre:
     1. Seleziona lingue: Inglese → Italiano
     2. Clicca "SELEZIONA FILE"
     3. Vai in "documents demo"
     4. Scegli "Physitek Letter [4].pdf" (piccolo, veloce)
     5. Clicca "SELEZIONA CARTELLA" per output
     6. Clicca "TRADUCI"
     7. Attendi ~1 minuto

═══════════════════════════════════════════════════════════════
💡 SISTEMA TECNICAMENTE AVANZATO
═══════════════════════════════════════════════════════════════

Il sistema implementa il blueprint.md completo:

✓ OCR MULTI-LIVELLO
   • Pre-processing: Deskewing, denoising, binarizzazione
   • Engine doppio: EasyOCR + Tesseract
   • Post-processing: Organizzazione paragrafi

✓ TRADUZIONE INTELLIGENTE
   • Chunking automatico per documenti lunghi
   • Preservazione layout originale
   • Gestione terminologia legale

✓ RILEVAMENTO AUTOMATICO
   • Il sistema rileva se il PDF è scannerizzato
   • Attiva OCR solo quando necessario
   • Ottimizza il processo per ogni tipo

🔔 IMPORTANTE PER DOCUMENTI SCANNERIZZATI
═══════════════════════════════════════════════════════════════

⏱️  TEMPO: I documenti scannerizzati richiedono più tempo
   • Il sistema deve:
     1. Convertire ogni pagina in immagine
     2. Applicare pre-processing
     3. Eseguire OCR
     4. Organizzare il testo
     5. Tradurre
     6. Generare output
   • È normale che ci voglia tempo
   • La progress bar mostra l'avanzamento

📊 QUALITÀ: La qualità della scansione influenza il risultato
   • Scansioni dritte funzionano meglio
   • 300 DPI è l'ideale
   • Documenti puliti danno risultati migliori
